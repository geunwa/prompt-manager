# 파이썬 프롬프트 관리 프로그램

## 1. 프로젝트 개요
이 프로그램은 자주 사용하는 AI 프롬프트를 효율적으로 저장하고 관리하기 위한 콘솔 기반 파이썬 프로그램입니다.  
사용자는 프롬프트를 추가, 조회, 검색, 삭제할 수 있으며, 즐겨찾기 기능을 통해 중요한 프롬프트를 따로 관리할 수 있습니다.

추가로 보너스 기능으로 JSON 파일 저장/불러오기와 카테고리별 Markdown 내보내기 기능을 구현했습니다.

---

## 2. 개발 환경
- Python 3.10 이상
- Visual Studio Code
- Git / GitHub

---

## 3. 실행 방법

### 1) 프로젝트 파일 준비
프로젝트 폴더 안에 파이썬 실행 파일이 있어야 합니다.

### 2) 프로그램 실행
터미널에서 아래 명령어를 실행합니다.

```bash
python main.py
```

또는 환경에 따라:

```bash
python3 main.py
```

---

## 4. 구현 기능

### 필수 기능
1. **프롬프트 추가**
   - 제목, 내용, 카테고리를 입력하여 새로운 프롬프트를 저장할 수 있습니다.

2. **프롬프트 목록 조회**
   - 저장된 프롬프트 전체 목록을 확인할 수 있습니다.

3. **프롬프트 검색**
   - 제목 또는 내용 기준으로 원하는 프롬프트를 검색할 수 있습니다.

4. **프롬프트 상세 보기**
   - 선택한 프롬프트의 상세 내용을 확인할 수 있습니다.

5. **즐겨찾기 설정**
   - 자주 사용하는 프롬프트를 즐겨찾기로 표시할 수 있습니다.

6. **프롬프트 삭제**
   - 저장된 프롬프트를 삭제할 수 있습니다.

---

## 5. 보너스 기능

### 1) JSON 파일 저장 및 불러오기
프로그램 종료 후에도 데이터가 유지되도록 프롬프트 정보를 JSON 파일에 저장하도록 구현했습니다.

- 프로그램 시작 시 JSON 파일이 있으면 기존 데이터를 불러옵니다.
- 프로그램에서 프롬프트를 추가/수정/삭제하면 변경 내용을 JSON 파일에 저장합니다.
- 파일이 없거나 비어 있는 경우에는 기본 프롬프트 데이터를 사용할 수 있도록 처리했습니다.

저장 파일 예시:
- `prompts.json`

### 2) 카테고리별 Markdown 내보내기
저장된 프롬프트를 카테고리별로 정리하여 Markdown 파일로 내보내는 기능을 구현했습니다.

- 카테고리 기준으로 프롬프트를 묶어서 정리합니다.
- Markdown 형식으로 저장하므로 문서화와 공유에 활용할 수 있습니다.
- 내보낸 파일은 보고서나 문서 정리 용도로 사용할 수 있습니다.

출력 파일 예시:
- `prompts_export.md`

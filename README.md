# 프롬프트 관리 프로그램

Python 콘솔(터미널) 기반으로 동작하는 프롬프트 관리 프로그램입니다.

이 프로그램은 프롬프트를 저장, 조회, 검색, 분류하고 즐겨찾기로 관리할 수 있으며, 데이터는 `prompts.json` 파일에 JSON 형식으로 저장됩니다.

## 프로젝트 목적

이전 과제에서 작성한 프롬프트를 체계적으로 관리할 수 있도록 다음 기능을 구현했습니다.

- 프롬프트 추가
- 전체 프롬프트 조회
- 카테고리별 조회
- 프롬프트 검색
- 프롬프트 상세 보기
- 즐겨찾기 추가/해제
- 즐겨찾기 목록 조회
- JSON 파일 저장

## 실행 방법

터미널에서 아래 명령어를 입력하여 프로그램을 실행합니다.

```bash
python main.py
```

## 주요 기능 설명

### 1. 프롬프트 추가
새로운 프롬프트를 제목, 내용, 카테고리와 함께 저장할 수 있습니다.

### 2. 전체 프롬프트 조회
저장된 모든 프롬프트를 목록 형태로 확인할 수 있습니다.

### 3. 카테고리별 조회
카테고리를 기준으로 프롬프트를 모아 볼 수 있습니다.

예시 카테고리:
- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

### 4. 프롬프트 검색
제목 또는 내용에 포함된 키워드로 원하는 프롬프트를 검색할 수 있습니다.

### 5. 프롬프트 상세 보기
선택한 프롬프트의 제목, 내용, 카테고리, 즐겨찾기 여부를 자세히 확인할 수 있습니다.

### 6. 즐겨찾기 기능
중요한 프롬프트를 즐겨찾기로 등록하거나 해제할 수 있습니다.

### 7. JSON 파일 저장
프롬프트 데이터는 `prompts.json` 파일에 저장되며, 프로그램을 다시 실행해도 기존 데이터가 유지됩니다.

## 프롬프트 카테고리

- 텍스트 생성: 블로그 글, 이메일, 기사, 소개문 등 텍스트 작성용 프롬프트
- 이미지 생성: 썸네일, 대표 이미지, 홍보 이미지 등 시각 자료 생성용 프롬프트
- 영상 생성: 영상 기획, 대본, 쇼츠 아이디어 등 영상 제작용 프롬프트
- 페르소나: 특정 역할이나 말투를 설정해 답변 품질을 높이는 프롬프트
- 자동화: 반복 작업, 게시글 생성, 데이터 정리 등 자동화 목적의 프롬프트
- 기타: 위 분류에 속하지 않는 일반 프롬프트

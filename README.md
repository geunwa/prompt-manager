# 프롬프트 관리 프로그램

Python 콘솔(터미널)에서 실행하는 프롬프트 관리 프로그램입니다.

이 프로그램은 프롬프트를 추가하고, 목록으로 확인하고, 카테고리별 조회, 검색, 상세 보기, 즐겨찾기 관리를 할 수 있습니다.  
프롬프트 데이터는 `prompts.json` 파일에 저장됩니다.

## 실행 방법

터미널에서 아래 명령어를 입력합니다.

```bash
python main.py
```

## 주요 기능

- 프롬프트 추가
- 전체 프롬프트 조회
- 카테고리별 조회
- 프롬프트 검색
- 프롬프트 상세 보기
- 즐겨찾기 추가/해제
- 즐겨찾기 목록 보기
- JSON 파일 저장

## 프롬프트 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 기본 등록 프롬프트

프로그램 시작 시 이전 과제에서 작성한 프롬프트 3개 이상이 기본 데이터로 등록되어 있습니다.

예시:
- 블로그 마케팅 코치 '나비' — 시스템 프롬프트
- 인스타그램 게시글 자동 생성 프롬프트
- 인스타그램 대표 이미지 생성 프롬프트

## 파일 구성

- `main.py` : 프로그램 실행 파일
- `prompts.json` : 프롬프트 데이터 저장 파일

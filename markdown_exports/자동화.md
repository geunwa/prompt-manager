# 자동화 프롬프트 모음

## 1. 인스타그램 게시글 자동 생성 프롬프트

- 카테고리: 자동화
- 즐겨찾기: 아니오
- 출처: 팀프로젝트 14조 (SNS 콘텐츠 자동화)

### 내용
다음 조건에 맞는 인스타그램 게시글을 작성하라.

주제: {{topic}}
톤앤매너: {{tone}}

반드시 아래 JSON 형식으로만 답하라.
설명 문장, 코드블록, 마크다운 없이 JSON만 출력하라.

{
  "platform": "Instagram",
  "caption": "string",
  "hashtags": "string"
}
